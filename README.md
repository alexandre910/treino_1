# MoveFit - Backend

API do projeto de academia virtual da FATEC Zona Sul.

Este repositório contém o **backend** do MoveFit (Java 21 + Spring Boot).

## Como o projeto está dividido

- **Backend (este repositório):** API REST com clientes, treinos, exercícios, agenda e assistente virtual.
- **Frontend:** aplicativo web em https://github.com/alexandre910/PulseFit-Fitness-App

## Tecnologias

- Java 21 e Spring Boot
- MySQL no AWS RDS
- Hospedagem na AWS EC2, com Nginx e HTTPS
- ElevenLabs (voz do assistente virtual)
